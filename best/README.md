# โมเดลกล้องที่ดีที่สุด (det / net · day / night)

จัดชุดเมื่อ 23 พ.ย. 2026 · โมเดลตรวจจับรถ 10 คลาส สำหรับรันบน DLPU ของกล้อง Axis (ARTPEC-8/9) ผ่านแอป enixma ซึ่งเปลี่ยนได้แค่ `detect.tflite` กับ labelmap

มีสองตระกูล แต่ละตระกูลมีโมเดลแยก day และ night โดย enixma เลือกโมเดลตามนาฬิกา (06–18 = day)
- **det:** SSDLite MobileDet 300×300 uint8 · fine-tune ต่อจาก tf_det_v10
- **net:** SSD MobileNetV2 quantized 300×300 uint8 · เทรนจาก COCO

## วิธีวัดผล

- **split `s1`:** แบ่งรูปที่คนตรวจแล้วเป็น train/val/test ตามกลุ่ม "กล้อง + วัน" เพื่อไม่ให้รูปจากช่วงเวลาเดียวกันอยู่ทั้งใน train และ test
  - ตั้งแต่ 22 พ.ย. ใช้สัดส่วน 80/10/10 (salt 147) ก่อนหน้านั้นใช้ 75/10/15
  - test ชุดใหม่เป็นส่วนหนึ่งของ test ชุดเดิม จึงไม่มีโมเดลในชุดนี้ตัวไหนเคยเห็นรูป test
- **slice `unseen`:** 846 รูป (day 561 / night 285) เป็นรูปที่ไม่เคยใช้เทรนโมเดลรุ่นเก่ากว่า s1 ด้วย ใช้ slice นี้เพื่อเทียบทุกรุ่นได้อย่างเป็นธรรม
- **geometry แบบ enixma:** ครอปกลางภาพตามสัดส่วนของโมเดล (1024×768 → 768×768 → 300×300)
  - ไม่นับ GT ที่อยู่นอกกรอบ และไม่นับ GT ที่เล็กกว่า 10 px ที่ขนาด 300
  - เลือกโมเดล day/night ตามนาฬิกาเหมือนบนกล้อง
- **ตัวชี้วัด:** mAP50 เฉลี่ย 10 คลาส (VOC AP, conf > 0.01)
  - เทียบรุ่นด้วย paired bootstrap 1000 รอบสุ่มรูป CI 95%
  - "ดีกว่า/แย่กว่า" = CI ของผลต่างไม่ครอบ 0 · "เสมอ" = ครอบ 0
- **เลือก checkpoint:** วัดทุก checkpoint ที่บันทึก (ทุก 5k step) บน val แล้วใช้ตัวที่ได้คะแนนสูงสุด

## ข้อจำกัดที่ทราบ

1. **det/night เสมอกับ v13 ทางสถิติ** คะแนนสูงกว่า 0.043 แต่ CI แตะ 0 (P(ดีกว่า) 0.95)
2. **test กลางคืนเล็ก** มีแค่ 285 รูปใน slice unseen ทำให้ CI กว้าง ผลต่างน้อยกว่าราว ±0.05 แยกไม่ออก
3. **day ยังเป็นรุ่น v13** v14 day กำลังเทรน
   - det day จะได้ผลราว 13:00 วันที่ 23 พ.ย.
   - net day จะได้ผลราว 20:00 วันเดียวกัน
   - ถ้าดีกว่าจะเปลี่ยนในชุดนี้
4. **mAP บนภาพนิ่งยังไม่ใช่ความแม่นในการนับรถ**
   - เกณฑ์ภาคสนามคือผิดได้ไม่เกิน 10 คันต่อรถ 100 คันที่ผ่าน
   - ผลล่าสุด (คลิปกลางคืน pk08, 22 พ.ย.) เป็นของรุ่นเก่ากว่าชุดนี้ ไม่ผ่านทั้งคู่
     - tf_det_v10 บนกล้องผิด 17/100
     - tf_net_v13 แบบ replay ผิด 15/100
   - โมเดลในชุดนี้ยังไม่ได้ทดสอบภาคสนาม
5. **ความผิดพลาดหลักที่พบมาตลอดคือสับสนคลาส** โดยเฉพาะ pickup↔car และ taxi↔car ดู AP ต่อคลาสได้ใน `eval/compare_same_test_unseen.txt` ของแต่ละช่อง
6. **ช่องเดียวกันใช้รุ่นต่างกัน** day เป็น v13 ส่วน night เป็น v14 แต่ทั้งคู่ใช้ input/output และ labelmap เดียวกัน จึงใส่ใน eap เดียวกันได้
